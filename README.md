# Movement Lab · 1차 레이아웃

HTML, CSS, JavaScript만으로 제작한 무브먼트랩 메인 페이지입니다. 프레임워크와 외부 패키지를 사용하지 않습니다.

디자인 기준: [Figma 디자인 · 517:2045](https://www.figma.com/design/IcgPzl4eMORbAIEqNpRCOS/?node-id=517-2045) — 1920 × 15404px.

모바일 기준: [Figma 디자인 · 517:2220](https://www.figma.com/design/IcgPzl4eMORbAIEqNpRCOS/?node-id=517-2220) — 430px. 767px 이하에서는 `styles/mobile.css`로 모바일 배치를 적용합니다. `scripts/mobile.js`는 화면 너비가 바뀌면 데스크톱 이미지와 `assets/mobile/`의 모바일 원본 이미지를 전환합니다. 베스트 상품은 터치로 가로 스크롤할 수 있습니다.

## 실행

Node.js 18 이상에서 작업 폴더의 터미널을 열고 실행합니다.

```sh
npm run dev
```

브라우저에서 http://localhost:3000 에 접속합니다. 설치할 패키지가 없어 `npm install`은 필요하지 않습니다. ES modules를 사용하므로 HTML 파일을 더블클릭하는 대신 로컬 서버를 사용하세요. VS Code Live Server로 `index.html`을 열어도 됩니다.

## 파일 구조

```text
index.html                       문서 진입점, 접근성 링크, 공통 대화상자
디자인토큰.md                    피그마에서 확인한 색상·서체·간격과 구현 규칙
styles/
  tokens.css                     공통 CSS 변수
  main.css                       CSS 연결, 초기화, 공통 버튼과 대화상자
  fonts.css                      원본 폰트 Regular·Italic·장식 서체 연결
scripts/
  main.js                        컴포넌트 조립, 검색, 상품 미리보기
  utils.js                       이미지·화살표·버튼 공통 마크업
  serve.js                       의존성 없는 로컬 개발 서버
components/
  header/                        로고·주 메뉴·유틸리티 메뉴
  hero/                          타이포그래피·브랜드 소개
  collection/                    가죽 소파 컬렉션·이미지 콜라주
  product-showcase/              신제품 3개 영역
  product-card/                  공통 상품 카드·베스트 상품 가로 스크롤
  featured-products/             페탈로 체어·페블 소파 이야기
  brands/                        브랜드 목록과 선택 상태
  portfolio/                     공간 프로젝트 3개
  footer/                        기업·고객센터 정보
assets/
  images/                        Figma에서 다운로드한 원본 SVG 38개
  fonts/README.md                 적용 폰트 출처·라이선스 안내
```

각 컴포넌트 폴더의 `.js`에서 HTML 마크업을, `.css`에서 스타일을 수정합니다. `scripts/main.js`에서 페이지 순서를 변경할 수 있습니다. 새 컴포넌트를 추가할 때 해당 폴더에 JS와 CSS를 만들고 `main.js`와 `styles/main.css`에 각각 연결하세요.

## 구현 범위

- 피그마의 전체 섹션 순서, 색상, 이미지, 비대칭 구도, 큰 제목을 반영했습니다.
- 페이지 전체는 Grid/Flex와 일반 문서 흐름으로 제작했습니다. 히어로·하단 장식 타이포그래피와 신제품 이미지 콜라주는 각 영역 안에서 원본 좌표 비율을 사용합니다.
- 768px 미만에서는 소개·콜라주·브랜드·포트폴리오를 좁은 화면에 맞게 재배치합니다. 모바일은 별도 시안이 없는 상태에서 설정한 임시 레이아웃입니다.
- Shop / Collections / Brand는 해당 섹션으로 이동합니다. Search는 현재 상품 이름을 검색합니다. 상품 More / Shop은 로컬 미리보기를 엽니다. 브랜드 목록은 선택 상태가 바뀝니다.
- 로그인·구매·장바구니 저장·고객 안내의 실제 서비스 연동은 아직 구현하지 않았으며 클릭하면 현재 제작 상태를 안내합니다. 브랜드는 선택 상태별 원본 이미지가 연결되어 호버·클릭·키보드 선택으로 이미지가 바뀝니다.

## 1차 인터랙션

참고: [Analogue Foundation](https://analoguefoundation.com/). 참고 사이트의 글자 등장, 메뉴 글자 전환, 이미지 패럴랙스와 드래그 콘텐츠를 현재 레이아웃에 맞춰 적용했습니다.

- 상단 제목과 장식 글자가 65ms 간격으로 순차 등장합니다.
- 본문·제목은 아래에서 나타나고, 주요 이미지는 페이드인으로 등장합니다. 이미지의 위에서 아래로 펼쳐지는 마스크와 등장 시 세로 이동은 제거했습니다. 화면에 진입할 때 한 번 재생합니다.
- 신제품의 네 이미지는 스크롤에 따라 서로 다른 속도로 최대 28px 움직입니다. 모바일에서는 이 이동을 끕니다.
- 신제품 영역에서 스크롤이 180ms 동안 멈추면 현재 화면 중앙의 영역에 있는 이미지가 2.4초에 걸쳐 6% 확대됩니다. 모바일 확대 폭은 3.5%입니다. 다시 스크롤하면 원래 배율로 돌아오며, 이미지 프레임의 크기와 배치는 유지합니다. 동작 줄이기 설정에서는 확대를 끕니다.
- 메인·컬렉션·베스트 상품·추천 상품·브랜드·포트폴리오 이미지에도 프레임 안의 패럴랙스와 느린 확대를 적용했습니다. 스크롤 중에는 이미지가 프레임 안에서 최대 18px 움직이고, 180ms간 멈추면 2.8초에 걸쳐 추가 확대됩니다. 모바일은 패럴랙스를 끄고 확대 폭만 줄여 적용합니다. 위에서 아래로 펼쳐지는 마스크 효과는 사용하지 않습니다. 이 공통 효과는 `scripts/image-motion.js`와 `styles/image-motion.css`에서 관리합니다.
- 신제품 3개 영역은 VP GLOBE → NUA TABLE → BAHN 순서로 전환됩니다. 데스크톱에서는 이전 영역이 머무는 동안 다음 영역이 아래에서 덮어 올라오고, 이전 영역은 최대 20% 어두워집니다. 각 영역의 이미지·제목·설명·버튼은 실제 화면 진입 순서대로 180ms 간격을 두고 한 번씩 등장합니다. 모바일과 동작 줄이기 설정에서는 영역 고정을 해제합니다.
- 메뉴·상품 카드 링크는 호버와 키보드 포커스에서 글자가 위로 전환됩니다. READ MORE 버튼은 세리프 서체와 상·하단 선을 사용하며, 문구가 오른쪽으로 36px 이동하고 왼쪽 화살표가 들어오는 동안 오른쪽 화살표는 빠져나갑니다. 상단 선은 200ms 시차로 다시 그려지며 전체 전환은 800ms입니다. 버튼 전용 스타일은 `styles/more-link.css`에 있습니다.
- 베스트 상품은 마우스로 잡아 가로로 이동할 수 있습니다. 드래그 중에는 상품 클릭을 막으며, 터치 스크롤과 목록 포커스 상태의 좌우 방향키도 지원합니다.
- 헤더는 아래로 스크롤하면 숨고 위로 스크롤하면 다시 나타납니다. 키보드 포커스가 있으면 표시합니다.
- OS의 동작 줄이기 설정에서는 등장·패럴랙스·커서 효과를 끄고 콘텐츠를 바로 표시합니다.

동작은 `scripts/interactions.js`, 강도와 전환 시간은 `styles/interactions.css`에서 수정합니다. 외부 애니메이션 라이브러리는 사용하지 않습니다. 브라우저 점검은 `scripts/check-interactions.js`에 있습니다(Node.js 22 이상 및 로컬 Chrome 디버깅 포트 9222 필요). 이미지·스크롤·드래그·클릭·모바일·동작 줄이기를 확인했습니다.

신제품 전환은 `components/product-showcase/product-showcase-motion.js`와 같은 폴더의 `product-showcase-motion.css`에서 관리합니다. 이미지의 원본 배치와 비율은 유지하며, 높이가 화면보다 긴 영역은 하단까지 스크롤한 후 고정합니다. 전용 점검 `node scripts/check-showcase.js`로 세 영역의 순차 등장, 12개 이미지의 로딩·비율, 겹침 순서, 역방향 스크롤, 모바일과 동작 줄이기를 확인할 수 있습니다(동일한 Chrome 디버깅 환경 필요).

## 다음 작업

브랜드 선택 상태는 Figma 535:1585(MUNITO), 535:1661(MARSET), 535:1771(OBLIQUE TABLE), 535:1847(MBIS), 535:1923(MAGICVAULT)를 반영했습니다. 기본 JACKSON CHAMELEON 이미지와 새 이미지 5개를 동일한 835:800 프레임에 배치하고 450ms 페이드로 전환합니다. 데스크톱 호버, 클릭·모바일 탭, 키보드 포커스·방향키·Home/End를 지원합니다. 이미지를 디코딩한 뒤 선택 상태와 동시에 갱신하며, 빠른 선택 전환에서 오래된 요청이 새 선택을 덮어쓰지 않습니다. 동작 줄이기에서는 즉시 교체합니다.

추천 상품 영역(517:2130)은 [In Common With](https://www.incommonwith.com/)의 Featured 영역을 참고했습니다. 1024px 이상에서 큰 이미지 옆 설명·상품 카드가 해당 행 안에서 고정되고, 행 끝에서 멈춥니다. 큰 이미지·상품 이미지를 클릭하면 미리보기가 열리며 호버·키보드 포커스에서 각각 2.5%·5% 확대됩니다. 이 영역에는 이전의 공통 자동 확대와 패럴랙스를 적용하지 않습니다. 모바일과 동작 줄이기에서는 고정을 해제합니다. 동작은 `components/featured-products/featured-products-motion.js`, 스타일은 같은 폴더의 CSS에서 관리합니다. 별도 전환용 이미지가 없어 참고 사이트의 대체 이미지 교차 전환은 추가하지 않았습니다.

Figma 노드 517:2159의 원본 폰트를 연결하고 제목·장식 글자·본문 줄바꿈·이미지 좌표를 보정했습니다. Cormorant Garamond는 공식 Google Fonts 파일을, 나머지 서체는 사용자 PC에 설치된 원본을 사용합니다. 폰트 출처와 배포 조건은 `assets/fonts/README.md`를 참고하세요. 상품·브랜드 상세 URL, 검색 데이터, 계정·장바구니는 실제 서비스 범위에 맞게 연결하면 됩니다.

푸터의 회사·고객센터 정보는 피그마 문구를 옮긴 것으로, 게시 전 실제 운영 정보를 확인하세요. 원본 이미지와 아이콘은 로컬 파일만 참조하며 임시 Figma 다운로드 URL을 런타임에 사용하지 않습니다.
