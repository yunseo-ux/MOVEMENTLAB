# 적용된 폰트

`styles/fonts.css`에서 Cormorant Garamond Regular/Italic, Helvetica Now Display Regular/Light, Pretendard Regular, Verandah Reverie를 로컬 폰트 파일로 연결했습니다.

Cormorant Garamond는 [Google Fonts 공식 저장소](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)에서 받았습니다. 가변 폰트의 400 굵기를 사용하며, SIL Open Font License를 `CormorantGaramond-OFL.txt`에 함께 보관했습니다.

Helvetica Now Display, Pretendard, Verandah Reverie는 사용자 PC에 설치된 원본 파일을 이 개인 작업의 로컬 미리보기에 연결했습니다. 폰트 이름은 `styles/tokens.css`에서 관리합니다.

Helvetica Now Display 및 PERSONAL USE ONLY 폰트의 웹 배포 권한은 별도로 확인해야 합니다. 파일 복사가 웹 배포 라이선스를 제공하는 것은 아닙니다.

이번 수정 대상인 Figma 노드 517:2159의 폰트는 모두 연결했습니다. 다른 신제품 섹션의 숫자에 쓰인 Valky는 이번 영역에 해당하지 않으며 파일이 없습니다.
